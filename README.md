# RB Tourism — Coming Soon

A responsive static Coming Soon page. The complete website is in `dist/` and can be uploaded directly to the document root of any static web host. No Node.js, build step, database, or server application is required.

The page uses the supplied brand guidelines' original vector logo, Deep Emerald (`#025A42`), Crimson (`#E3163D`), Warm Ivory (`#F7F4EE`), Charcoal (`#23291F`), and Mist Gray (`#C9CDC6`). Inter is the approved digital fallback and is hosted locally; its license is included in `dist/assets/Inter-LICENSE.txt`.

The displayed assistance number is `01810-688210`. Its call link uses the international format `tel:+8801810688210`.

The lagoon image is original AI-generated scenery, not a photograph of a named destination. No visitor tracking, subscription form, or third-party runtime is included.

To preview locally, serve `dist/` with any static HTTP server, for example `python3 -m http.server 4173 --directory dist`.
